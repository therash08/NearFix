# NearFix 🚀

NearFix is a modern Flutter-based local service finder application that helps users discover nearby trusted service providers quickly and efficiently.

The platform connects customers with local professionals such as electricians, plumbers, tutors, repair technicians, cleaning services, and many more through smart location-based search and booking features.

---

## ✨ Features

- 🔍 Smart service search
- 📍 Nearby provider discovery
- 🗺️ Google Maps integration
- 📅 Booking system
- 💬 AI-powered chatbot assistant
- ⭐ Ratings & reviews
- ❤️ Favorite providers
- 📞 One-tap call & chat
- 🔐 Multi-role authentication system

---

## 👥 User Roles

### 👤 Customer/User

- Search nearby services
- Book providers
- Rate & review services
- Save favorite providers

### 🔧 Service Provider

- Manage services
- Accept/reject bookings
- Update availability & location
- View earnings and analytics

### 🛠️ Admin

- Manage users & providers
- Verify provider accounts
- Monitor bookings & reports
- Manage service categories
